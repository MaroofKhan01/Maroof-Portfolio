MAROOF KHAN PORTFOLIO — QUICK START

1. Extract this folder to your Desktop.
2. Open the Maroof-Portfolio folder in Visual Studio Code.
3. Add your own portrait photo at images/profile.jpg (JPG format recommended).
4. Open index.html in Chrome. Easiest option: install the Live Server extension in VS Code, right-click index.html, and choose “Open with Live Server”.
5. Update project links in index.html when you have the exact GitHub repository URL for each project.
6. LinkedIn was not provided, so no LinkedIn link is shown.

Files:
- index.html: website content
- style.css: colors, layout, responsive design and animation
- script.js: mobile menu, photo fallback, reveal effects and footer year
